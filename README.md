# Chrome extension for GitHub (PR student comment icons)

Injects 4 clickable icons into GitHub Pull Request comments to quickly reply to student work:

- 👍 **Like** — posts a random "well done" image (optionally merges the PR afterwards)
- 🔗 **Broken link** — student did not post the GitHub Pages URL
- 👎 **Pages broken** — the posted URL does not work
- 🆘 **SOS** — the result is not what was asked
